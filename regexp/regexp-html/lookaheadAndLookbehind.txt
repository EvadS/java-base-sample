# Regex lookahead, lookbehind and atomic groups
(Опережающие и ретроспективные проверки)
(?=) - positive lookahead
(?!) - negative lookahead
(?<=) - positive lookbehind
(?<!) - negative lookbehind

(?>) - atomic group
---

### Опережающая проверка(positive lookahead)

Синтаксис опережающей проверки: X(?=Y).        : найди X при условии, что за ним следует Y
let str = "1 индейка стоит 30€";
/\d+(?=€)/; // 30  найдём число, после которого есть знак валюты €.

содержимое скобок (?=...) не включается в результат 30.
---------------------------------
более сложные проверки, например X(?=Y)(?=Z)
```
\d+(?=\s)(?=.*30)
```
пояснение: ищем  \d+ при условии, что за ним идёт пробел, и где-то впереди есть 30:
Найти X.
Проверить, идёт ли Y сразу после X (если нет – не подходит).
Проверить, идёт ли Z сразу после X (если нет – не подходит).

### Негативная опережающая проверка ( negative lookahead)
```
Синтаксис: X(?!Y)
```
означает: найди такой X, за которым НЕ следует Y.
пример
pattern:   \d+(?!€)
текст  : 2 индейки стоят 60€

### Ретроспективная проверка (Look behind positive)  (?<=Y)X,
(?<=Y)X, ищет совпадение с X при условии, что перед ним ЕСТЬ Y.

### Отрицательная Ретроспективная проверка ( negative lookahead)
(?<!Y)X, ищет совпадение с X при условии, что перед ним НЕТ Y.






----------------------
bar(?=bar)     finds the 1st bar ("bar" which has "bar" after it)
bar(?!bar)     finds the 2nd bar ("bar" which does not have "bar" after it)
(?<=foo)bar    finds the 1st bar ("bar" which has "foo" before it)
(?<!foo)bar    finds the 2nd bar ("bar" which does not have "foo" before it)
