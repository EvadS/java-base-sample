
буква от 2 до 5 раз
```
hel{2,5}o, world
```
второе число можно опустить
```
hel{2,}o, world
```

hello, {1,}world!{0,}

```
(hello|привет|bonjour), world
```

сделать, чтобы среди множества опциональных вариантов хотя бы один все-таки присутствовал?
```
hello *[, ] *world
```

Здесь у нас есть два варианта на выбор:
запятая, с которой могут быть пробелы (а могут и не быть);
пробелы, не менее одного.
```
hello( *, *| +)world
```
