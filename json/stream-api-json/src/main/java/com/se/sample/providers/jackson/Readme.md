Streaming API
The streaming API offered by Jackson is a powerful feature that allows for efficient reading and writing
of JSON data. With the streaming API, you can process JSON data in a streaming fashion,
without the need to load the entire JSON structure into memory. This is especially useful when 
working with large JSON data sets, as it minimizes memory usage and improves processing speed
